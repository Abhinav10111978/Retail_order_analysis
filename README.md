# Retail_order_analysis
Retail Orders Data Analysis using core Python


## 01. Project Overview
This project focuses on analyzing retail order data using Python. The main objective is to understand order information, calculate revenue, and generate useful insights from a retail dataset.

It is a beginner-level data analysis project developed to practice Python programming and real-world CSV data handling.

## 02. Project Objectives
- Analyze retail order information.
- Calculate total revenue after applying discounts.
- Identify the top 10 orders based on revenue.
- Separate order data based on categories and delivery status.
- Generate separate CSV files for analyzed data.

## 03. Technologies & Concepts Used
- **Python**
- **CSV Module** – Reading and writing CSV files.
- **Lists & Dictionaries** – Storing and managing data.
- **For Loops & Conditional Statements** – Processing records.
- **Lambda Functions** – Custom sorting logic.
- **Sorting** – Ranking orders by revenue.
- **File Handling** – Creating separate output files.

## 04. Analysis Performed

1. **Revenue Calculation:** Calculated order revenue using quantity, unit price, and discount percentage.

2. **Top 10 Orders:** Sorted orders from highest to lowest revenue and identified the top 10 orders.

3. **Category-wise Analysis:** Separated records based on product categories.

4. **Delivery-based Analysis:** Created separate files for delivered orders.

5. **CSV File Generation:** Exported processed data into separate CSV files.

## 05. Project Structure

- `Project_retail_orders.ipynb` – Main Python analysis notebook.
- `README.md` – Project documentation.
- `03_Report.txt` – Project report.
- CSV files – Dataset and generated analysis outputs.
